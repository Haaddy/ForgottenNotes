# Video Later

Расширение для Chrome: личная библиотека полезных ссылок и видео вместо десятка открытых
вкладок «посмотреть потом». Всё хранится локально в браузере, без аккаунтов и серверов.

## Что умеет

- **Сохранить текущую вкладку** из popup, по горячей клавише `Alt+Shift+S` или через
  контекстное меню страницы/ссылки.
- **Автозаполнение**: заголовок, описание, превью, автор/канал, длительность, тип
  (`Видео / Статья / Код / Ссылка`). Для YouTube — превью и таймкод, с которого вы
  смотрели видео.
- **Теги** — свободные, создаются на лету, с автодополнением и цветом.
- **Заметка** — короткое поле «зачем сохранил / что посмотреть».
- **Статусы**: «Хочу посмотреть», «Посмотрел», «В архиве».
- **Избранное**: пометка звёздочкой и отдельный фильтр для важных записей.
- **Библиотека**: поиск по названию/заметке/тегам, фильтры по тегам, типу и статусу,
  сортировка, сетка или список, массовые действия, редактирование.
- **Дедупликация**: `utm_*`-метки и прочий мусор отбрасываются, повторное сохранение
  обновляет запись, а не создаёт дубль.
- **Экспорт/импорт JSON** для бэкапа и переноса.
- Светлая/тёмная/системная тема.

## Стек

- **TypeScript + React 19** — UI
- **WXT 0.21** — сборка расширения (Manifest V3, автогенерация `manifest.json`, HMR)
- **Vite + Tailwind CSS 4** — стили
- **Dexie (IndexedDB)** — локальное хранилище
- Chrome / Edge, Manifest V3

## Быстрый старт

```powershell
npm install
npm run build
```

Дальше загружаем расширение в браузер:

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите **Режим разработчика** (Developer mode).
3. Нажмите **Загрузить распакованное** (Load unpacked).
4. Выберите папку **`.output\chrome-mv3`** из этого проекта.
5. Закрепите «Video Later» на панели (иконка пазла → булавка).

После первого запуска автоматически откроется библиотека.

### Про `npm run dev`

`npm run dev` собирает проект с вотчером и пытается самоcтоятельно запустить Chrome.
В обычном Google Chrome начиная с версии 137 флаг `--load-extension` отключён, поэтому
автозапуск может не сработать. Это ограничение браузера, а не проекта. Надёжный путь:

```powershell
npm run build
# затем в chrome://extensions нажать «Обновить» у расширения
```

Для проверки типов: `npm run compile`. Пересобрать иконки: `npm run icons`.

## Как раздать расширение друзьям

Есть три способа — от самого простого к самому правильному.

### 1. ZIP-файл (для друзей без Node.js)

Соберите архив — в нём уже готовое расширение, ничего устанавливать не нужно:

```powershell
npm run build
npm run zip
```

Получится `.output\video-later-<версия>-chrome.zip` (~170 КБ). Положите этот файл в
репозиторий на GitHub → Releases → «Create a new release» → прикрепите zip. Друзьям
достаточно скачать его, распаковать в любую папку и выполнить шаги 2–5 из раздела
«Быстрый старт» (Без Node и клонирования).

Важно: при обновлении версии увеличьте `version` в `wxt.config.ts` и выпустите новый zip.

### 2. Из исходников на GitHub

Публичный репозиторий с инструкцией из этого README. Друзьям понадобится Node.js 20+:

```bash
git clone <ваш-репозиторий>
cd video-later
npm install
npm run build
```

Дальше — как в «Быстром старте» (загрузить `.output\chrome-mv3`).

### 3. Chrome Web Store (официальный способ)

Нужен разовый взнос разработчика ($5) и модерация Google. Плюсы: обновления
распространяются сами, и не нужно включать режим разработчика. Минусы: отзыв
занимает время, а расширение с запросом `activeTab`/`scripting обычно проходит
без проблем.

Совет: не плачьте $5 ради нескольких друзей — zip-способ полностью рабочий. Но знайте
недостаток zip-варианта: Chrome при каждом запуске показывает плашку
«Отключить расширения для разработчика» — это нормально, просто закройте её.

## Как пользоваться

1. Откройте видео/статью → нажмите иконку расширения.
2. При желании добавьте теги и заметку, поправьте название → **Сохранить**.
3. Хотите сохранить без формы — нажмите `Alt+Shift+S` (настраивается в
   `chrome://extensions/shortcuts`). На иконке на секунду появится `✓`.
4. Вся библиотека — кнопка **«Вся библиотека»** в popup.

В библиотеке:

- `/` — быстрый переход к поиску;
- `+ Добавить` — добавить ссылку вручную;
- клик по тегу в левой колонке — фильтр (можно несколько);
- иконки на карточке: открыть, редактировать, отметить просмотренным, в архив, удалить;
- чекбокс на карточке → массовые действия сверху;
- «Экспорт» / «Импорт» — резервная копия JSON. **Импорт заменяет** текущую библиотеку.

## Где хранятся данные

Всё лежит в IndexedDB браузера (база `video-later`), привязано к профилю Chrome.
Ничего не отправляется в интернет. Превью видео подгружаются по ссылке с CDN
(`i.ytimg.com` и т.п.) и в базе не кэшируются.

Удаление расширения удаляет и данные, поэтому делайте экспорт.

## Структура проекта

```
entrypoints/
  background.ts        # service worker: хоткей, контекстное меню, сохранение, значок
  popup/               # быстрое добавление текущей вкладки
  library/             # полная библиотека (отдельная вкладка)
lib/
  db.ts                # Dexie: items, tags + операции
  meta.ts              # сбор og-метаданных со страницы (через scripting.executeScript)
  url.ts               # канонизация URL, YouTube ID, таймкоды, детект типа
  types.ts             # модель данных
  format.ts            # длительность, даты, склонения
  tags.ts              # цвета тегов
  theme.ts             # тема (light/dark/system)
components/            # карточки, теги, диалоги, иконки
assets/tailwind.css    # стили
scripts/make-icons.ps1 # генерация иконок
```

## Права расширения

| Право | Зачем |
|---|---|
| `activeTab`, `scripting` | прочитать заголовок/превью текущей страницы только по действию пользователя |
| `storage`, `unlimitedStorage` | локальное хранилище без лимитов синхронизации |
| `contextMenus` | пункты «Сохранить…» в меню |
| `commands` | горячая клавиша |

Доступа ко всем сайтам (`<all_urls>`) расширение не просит: скрипт выполняется на
активной вкладке только после клика/хоткея.

## Чек-лист ручной проверки

1. Открыть обычную статью → popup → сохранить → запись появилась в библиотеке.
2. Открыть YouTube → сохранить → есть превью, канал, длительность, «Начинать с …».
3. Сохранить ту же ссылку ещё раз → в popup «Уже в библиотеке», запись не дублируется.
4. Поставить статус «Посмотрел», отфильтровать по тегу, найти через поиск.
5. Перезапустить браузер → хоткей `Alt+Shift+S` на открытой странице → появляется `✓`.
6. Экспорт → удалить запись → импорт → запись вернулась.
7. Тёмная/светлая тема, вид «список», массовое выделение и удаление.

## Что можно добавить дальше

- Кэширование превью в IndexedDB для офлайна.
- Синхронизация между устройствами (свой бэкенд или Supabase).

- Папки/коллекции поверх тегов, «плейлисты» из сохранённых видео.
- Экспорт в закладки браузера, авто-теги для доменов.
