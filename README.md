# Forgotten Notes

**Forgotten Notes** — расширение для Google Chrome, которое помогает сохранять полезные
ссылки, видео и короткие личные заметки, чтобы не держать десятки вкладок открытыми.

Все данные хранятся локально в браузере. Аккаунт, сервер и синхронизация не требуются.

## Возможности

- Сохранение текущей страницы из popup, по `Alt+Shift+S` или через контекстное меню.
- Поддержка полезных ссылок, видео, статей и репозиториев.
- Автоматическое заполнение названия, описания, превью, автора и длительности.
- Для YouTube — превью и сохранение таймкода, с которого нужно начать просмотр.
- Короткие текстовые заметки к каждой ссылке.
- Свободные теги с автодополнением и цветами.
- Избранное со звёздочкой и отдельным фильтром.
- Статусы: **Хочу посмотреть**, **Посмотрел**, **В архиве**.
- Поиск по названию, ссылке, заметке и тегам.
- Фильтры по статусу и тегам.
- Сортировка, режим сетки или списка, редактирование и массовые действия.
- Защита от дублей: повторное сохранение не создаёт копию записи.
- Экспорт и импорт библиотеки в JSON.
- Светлая, тёмная и системная тема.

## Скачать и установить готовую версию

> Этот раздел предназначен для обычных пользователей. Node.js и исходный код не нужны.

### 1. Скачать архив

Откройте страницу [Releases](https://github.com/Haaddy/ForgottenNotes/releases) и выберите
последний релиз. Внизу страницы, в разделе **Assets**, скачайте файл с названием вроде:

```text
video-later-0.1.0-chrome.zip
```

Или откройте [последний релиз](https://github.com/Haaddy/ForgottenNotes/releases/latest).

### 2. Распаковать архив

Распакуйте ZIP-файл в постоянную папку, например:

```text
C:\Users\ВашеИмя\Extensions\ForgottenNotes
```

Не удаляйте эту папку после установки — Chrome загружает расширение именно из неё.

### 3. Подключить расширение в Chrome

1. Откройте в адресной строке:
   ```text
   chrome://extensions
   ```
2. Включите переключатель **Режим разработчика** в правом верхнем углу.
3. Нажмите **Загрузить распакованное**.
4. Выберите распакованную папку, внутри которой находится файл `manifest.json`.
5. При желании закрепите Forgotten Notes на панели браузера через значок пазла.

> ZIP-файл нельзя выбирать напрямую. Сначала его нужно распаковать, затем выбрать папку
> с `manifest.json`.

### 4. Начать пользоваться

1. Откройте видео или статью.
2. Нажмите иконку Forgotten Notes.
3. Добавьте заметку и теги, если нужно.
4. Нажмите **Сохранить**.
5. Откройте **Вся библиотека**, чтобы найти, отфильтровать или отредактировать запись.

Для быстрого сохранения текущей страницы используйте `Alt+Shift+S`. Горячую клавишу
можно изменить в `chrome://extensions/shortcuts`.

### Важное ограничение Chrome

При установке через **Загрузить распакованное** включается режим разработчика, поэтому
Chrome может показывать предупреждение о расширениях для разработчиков. Это нормально
для установки из GitHub. Официальная публикация в Chrome Web Store убирает это
ограничение, но требует отдельной публикации и модерации.

## Данные и резервная копия

Данные хранятся в IndexedDB локального профиля Chrome. Они не отправляются на сервер.
У каждого пользователя своя отдельная библиотека.

Для резервной копии в библиотеке нажмите **Экспорт**. Будет скачан JSON-файл. Для
восстановления нажмите **Импорт** и выберите этот файл.

> Удаление расширения может удалить локальные данные, поэтому регулярно делайте экспорт.

## Для разработчиков

### Стек

- TypeScript + React 19
- WXT 0.21 и Manifest V3
- Vite + Tailwind CSS 4
- Dexie + IndexedDB
- Chrome / Edge

### Запуск из исходников

Требуется Node.js 20 или новее:

```powershell
git clone https://github.com/Haaddy/ForgottenNotes.git
cd ForgottenNotes
npm install
npm run compile
npm run build
```

После сборки загрузите папку в Chrome:

```text
.output\chrome-mv3
```

Откройте `chrome://extensions` → включите режим разработчика → **Загрузить
распакованное** → выберите `.output\chrome-mv3`.

### Создание нового релиза

Проверьте код, соберите ZIP и прикрепите его к GitHub Release:

```powershell
npm run compile
npm run zip
```

Готовый архив появится здесь:

```text
.output\video-later-0.1.0-chrome.zip
```

Для новой версии увеличьте номер версии в `wxt.config.ts`, создайте новый тег, например
`v0.1.1`, и прикрепите новый ZIP к отдельному Release.

## Структура проекта

```text
entrypoints/
  background.ts        # хоткей, контекстное меню и сохранение
  popup/               # быстрое добавление текущей вкладки
  library/             # полная библиотека
lib/
  db.ts                # Dexie и операции с данными
  meta.ts              # сбор метаданных страницы
  url.ts               # URL, YouTube ID и таймкоды
  types.ts             # модели данных
components/            # карточки, теги, диалоги и иконки
assets/tailwind.css    # стили
scripts/make-icons.ps1 # генерация иконок
```

## Права расширения

| Право | Назначение |
|---|---|
| `activeTab`, `scripting` | чтение метаданных текущей страницы после действия пользователя |
| `storage`, `unlimitedStorage` | локальное хранение |
| `contextMenus` | пункты сохранения в контекстном меню |
| `commands` | горячая клавиша |

Расширение не запрашивает доступ ко всем сайтам. Скрипт выполняется только на активной
вкладке после действия пользователя.
